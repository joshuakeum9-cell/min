# Bundled fonts

Vendored so the app never contacts Google. Latin subset only, as served by Google Fonts.

- `archivo-latin-wght.woff2`: Archivo v25, variable weight axis 100-900, covering the 400/500/600 the UI uses. Source: https://fonts.gstatic.com/s/archivo/v25/k3kPo8UDI-1M0wlSV9XAw6lQkqWY8Q82sLydOxI.woff2 . Licence: SIL Open Font License 1.1.
- `ibm-plex-mono-400-latin.woff2`: IBM Plex Mono v20, weight 400. Source: https://fonts.gstatic.com/s/ibmplexmono/v20/-F63fjptAgt5VM-kVkqdyU8n1i8q1w.woff2 . Licence: SIL Open Font License 1.1.
- `ibm-plex-mono-500-latin.woff2`: IBM Plex Mono v20, weight 500. Source: https://fonts.gstatic.com/s/ibmplexmono/v20/-F6qfjptAgt5VM-kVkqdyU8n3twJwlBFgg.woff2 . Licence: SIL Open Font License 1.1.
- `newsreader-400-latin.woff2`: Newsreader v26, weight 400, the 16pt optical-size instance Google Fonts serves for a plain weight-400 request. Source: https://fonts.gstatic.com/s/newsreader/v26/cY9qfjOCX1hbuyalUrK49dLac06G1ZGsZBtoBCzBDXXD9JVF438weI_wC-ZF.woff2 . Licence: SIL Open Font License 1.1.

`OFL.txt` carries the full licence text and all three copyright notices. It ships inside the app,
which is what the OFL asks of anyone redistributing the files. Each copyright line there is the one
its upstream project publishes; the source URL above is the exact file this app vendors.
